Restore Instructions
Warning: Restoring a backup will overwrite all current data. This action cannot be undone!
To restore from a backup:
  1. Download the backup file you want to restore
  2. Stop the application server
  3. For SQLite: Replace the database file with the backup
  4. For MySQL/MariaDB: Use mysql -u username -p database_name < backup_file.sql
  5. Restart the application server

Note: For production environments, it's recommended to test the restore process in a staging environment first.
